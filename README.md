# interpreter-opd
Voice-first two-way interpreter for Hindi/Bhojpuri-speaking patients and Tamil-speaking doctors in Chennai government hospital OPDs.

## Quick start

```
docker compose up --build
```

Then open http://localhost:3000. No `.env` or API keys are required — the app runs in demo mode
with browser-based voice until you add keys (see `.env.example`).

(Full documentation lands at the end of the build — see CLAUDE.md for the build plan.)
